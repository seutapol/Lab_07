# Lab 7.1

Code Splitting дегеніміз не?

Code Splitting – бұл қосымшаны кіші бөліктерге (bundle) бөлу әдісі. 
Қолданушыға барлық кодты бірден жүктемей, тек қажет болған бөлігін ғана жүктеуге мүмкіндік береді.

Бұл бастапқы жүктеу уақытын жылдамдатады және өнімділікті арттырады.


lazy() не үшін қолданылады?

lazy() – React функциясы, ол компоненттерді динамикалық түрде жүктеуге мүмкіндік береді.

Мысалы:

```ts
const Dashboard = lazy(() => import("./pages/Dashboard"));

Error Boundary дегеніміз не?

Error Boundary – бұл React class компоненті, 
ол өзінің ішіндегі компоненттерде пайда болған JavaScript қателерін ұстап алады 
және қосымшаның толық бұзылып кетуіне жол бермейді.


Error Boundary не үшін қажет?

Егер lazy арқылы жүктелетін компонент қате жіберсе, 
қосымша толықтай crash болуы мүмкін.

Error Boundary осы қателерді ұстап, 
пайдаланушыға түсінікті хабарлама көрсетеді.


## Қалай жұмыс істейді?

Error Boundary келесі әдісті қолданады:

- getDerivedStateFromError() – қате болған кезде fallback UI көрсету үшін
- fallback – пайдаланушыға көрсетілетін қате экраны

Мысалы:

```tsx
<ErrorBoundary fallback={<ErrorFallback />}>
  <Suspense fallback={<Loading />}>
    <Routes />
  </Suspense>
</ErrorBoundary>
